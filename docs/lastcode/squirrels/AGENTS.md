# Squirrels project guidance

This directory is the durable home for Squirrels research and documentation.

- Keep research and documentation changes on the open Squirrels base PR.
- Stack later implementation PRs on the base PR head and link them back to the relevant research document.
- Keep the base PR open until an explicit integration decision.
- Update `README.md` when the index or the current base PR reference changes.
- Preserve the user's original goals and unresolved questions; do not treat a later status request as cancellation.

The current project and base PR are discoverable from the GitHub Project named **Squirrels** and the base PR body.
