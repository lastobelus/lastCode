> I chase squirrels.
> Threads chase squirrels with me.
> However, I need threads to keep track of all the squirrels, and of goals set at the beginning of the thread, or at points within it.
> The way my brain works, if I say something to the thread, my brain thinks "ok, we don't have to keep that in mind" so if the thread forgets all about it, due to compaction, or chasing squirrels with me, or assuming because I asked for status on thing a it can forget about things b,c,d, or assuming when I ask "what's next?" or "anything left for this thread?" that I'm only referring to the last immediate set of concerns in the thread I get hurt, disappointed, frustrated, sad, and lonely.
> I've noticed that threads pop task lists that are attached to the composer, and check things off on them.
> However I've also noticed that when I ask a question or do a steer or identify a problem (or squirrel), they forget all about them and never refer back to them, regardless how unfinished they were.
>
> What can we do? Use subagents to do up-to-date research on prompting & agent guidance recommendations.
> Identify how the thread-managed task lists work, and how I can leverage them better.
> Things I'm willing to consider:
> - lastcode features, including possibly accessing / persisting /editing / annotating thread-initiated task lists
> - skills, like a "what's next?" skill and/or a "anything left for this thread?" skill, that potentially use agents to look through threads for unfinished/unstarted work
