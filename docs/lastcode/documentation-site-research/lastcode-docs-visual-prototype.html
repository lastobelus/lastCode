Resumable project actions

Agents can start a Project Action and then pause while it runs. LastCode wakes the thread when the Action finishes; in the meantime, you can inspect or cancel it.

A running Action stays visible above the composer, with controls for its terminal and cancellation.

Why it exists

We added this because we were tired of paying the polling tax: wasting turns and tokens checking whether a command was done.

Configure a resumable Action

  1. Open the Project Action.

    From project settings, create an Action or edit the one that runs your long command.

  2. Allow the agent to resume.

    Enable Allow Codex and Claude to run and resume, then save the Action.

  3. Ask the agent to run it.

    The Action gets its own terminal. The agent can pause its turn, and LastCode follows up after the command exits.

While the Action is running

The thread shows the Action name, elapsed time, and running state. Open its terminal to inspect live output, or cancel it from the thread. LastCode waits for the Action to finish and for the thread to be idle before sending the follow-up.

Limits and recovery

LastCode does not restart a command after an interruption.

If the app restarts after the command finishes but before the follow-up arrives, choose Resume agent to deliver the saved result or Discard to remove it.
